# 测试闯关 · 零基础软件测试学习平台

一个**闯关式**的软件测试自学项目，专为零基础想做初级功能测试员的人设计。
学完即可覆盖求职要求的核心技能：测试用例、缺陷报告、SQL 数据核对、接口测试、Python 脚本阅读。

## 特性

- 🎮 **游戏化闯关**：15 个关卡循序渐进，通关获得经验值，进度自动存档
- 🗄️ **真·SQL 沙箱**：浏览器内即可运行 SQL，不用装数据库，边学边练
- 🐍 **Python 预测练习**：先猜输出再揭晓，训练代码阅读能力
- 💾 **进度持久化**：SQLite 数据库保存学习进度，关掉再打开不丢失
- 🧠 **通俗易懂**：全程中文，用生活例子讲概念，不堆术语

## 快速开始

### 1. 安装 Node.js
去 https://nodejs.org/ 下载 **LTS 版本**，安装时一路点"下一步"即可。

### 2. 双击启动
双击本文件夹里的 **`start.bat`**。
- 第一次运行会自动安装依赖并构建，需要 1-3 分钟，请耐心等待。
- 看到绿色的 `启动成功！` 字样就成功了。
- 脚本会自动释放被占用的 3000 端口，所以重复双击也不怕冲突。

### 3. 打开浏览器
访问 **http://localhost:3000**

### 停止服务（三选一）
- **最简单**：双击 **`stop.bat`**，自动关闭服务并释放端口。
- 在黑色命令行窗口按 `Ctrl + C`。
- 任务管理器里结束 `node` 进程。

## 常见问题

**Q：双击 start.bat 没反应或闪退？**
A：start.bat 会调用 PowerShell。如被安全软件拦截，可右键 start.bat → "以管理员身份运行"。脚本出错时会停在窗口里显示中文报错，不会一闪而过，把报错截图发出来即可。

**Q：提示"端口 3000 被占用"？**
A：双击 `stop.bat` 先关掉旧服务，再双击 `start.bat`。或直接重启电脑。

**Q：关了黑窗口，服务还在跑怎么办？**
A：黑窗口只是控制台，进程可能仍在后台。双击 `stop.bat` 即可彻底关闭。

**Q：SQL 沙箱运行没反应？**
A：首次使用需要联网下载 sql.js 的 wasm 文件（约 1MB），稍等片刻即可。

**Q：想重置学习进度？**
A：首页底部有"重置全部进度"按钮。

**Q：想自己加关卡？**
A：编辑 `frontend/src/data/levels.js`，照着已有格式加一个关卡对象，保存后重新双击 start.bat 即可。
